Создай кроссплатформенное веб-приложение (PWA) для изучения английских слов школьниками 1–2 классов с поддержкой русского и латышского языков перевода. Приложение должно разворачиваться на GitHub Pages (или Vercel) и синхронизировать прогресс между компьютером и телефоном через Supabase.

### 1. Стек технологий
- Фронтенд: React / Vite + Tailwind CSS + Lucide Icons + Canvas-Confetti
- PWA: поддержка установки на домашний экран (manifest.json, service worker)
- База данных и авторизация: Supabase (Auth + PostgreSQL)
- Озвучка: Web Speech API (синтезатор речи для английского произношения)

### 2. Целевая аудитория и дизайн
- Школьники 7–8 лет (1–2 класс): крупные контрастные кнопки, яркий дружелюбный детский интерфейс, понятная анимация, отсутствие мелкого служебного текста.
- Поддержка двух языков интерфейса и перевода: Русский (RU) и Латышский (LV) с быстрым переключением в шапке.

### 3. Структура данных слов
Данные формируются из CSV-файла (в файле темы заданы отдельными строками-заголовками, а под ними строки из 3 колонок: английское слово, перевод на латышский, перевод на русский). 
Создай скрипт или функцию парсинга этого CSV в структуру JSON:
```json
[
  {
    "topic_id": "animals",
    "topic_name": { "ru": "Животные", "lv": "Dzīvnieki" },
    "words": [
      { "id": "1", "en": "cat", "lv": "kaķis", "ru": "кошка" },
      { "id": "2", "en": "dog", "lv": "suns", "ru": "собака" }
    ]
  }
]
