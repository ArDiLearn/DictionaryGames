# 🌟 WordyKids — Изучение английских слов для 1–2 класса

Красочное, адаптивное прогрессивное веб-приложение (**PWA**) для школьников 7–8 лет (1–2 класс) для изучения английских слов с переводом на **русский** и **латышский** языки.

---

## 🚀 Особенности и возможности

- 🎮 **5 интерактивных игровых режимов:**
  - 🎴 **Карточки (Flashcards):** двусторонние обучающие карточки с произношением и отметкой «Знаю!» / «Повторить».
  - 🎯 **Викторина (Quiz):** 4 крупные цветные кнопки с моментальной обратной связью.
  - 🔤 **Собери слово (Word Builder):** интерактивная сборка английского слова из кубиков-букв.
  - 🧩 **Найди пару (Match Pairs):** сопоставление английских карточек с переводом.
  - 🎧 **На слух (Audio Quiz):** тренировка восприятия английской речи на слух без подглядывания в текст.
- 🗣️ **Озвучка:** встроенный синтезатор речи **Web Speech API** со сниженным для первоклассников темпом (0.85x) для чёткого восприятия фонетики.
- 🌐 **Два языка перевода и интерфейса:** Русский (**RU 🇷🇺**) и Латышский (**LV 🇱🇻**) с мгновенным переключением в шапке.
- 📱 **Кроссплатформенность и PWA:** работает на смартфонах, планшетах и компьютерах; устанавливается на домашний экран («Добавить на главный экран») и работает оффлайн благодаря Service Worker.
- ☁️ **Синхронизация прогресса через Supabase:**
  - **Offline-first:** приложение полноценно работает локально (в LocalStorage) без интернета и без учётной записи.
  - При подключении к Supabase (через `.env` или форму в шапке) прогресс (звёздочки, статистика по словам, стрик) синхронизируется между телефоном и компьютером.
- 📚 **23 темы и 209 слов** из учебной программы 1–2 классов (Числа, Цвета, Семья, Животные, Одежда, Дом, Еда, Действия и др.).

## 🛠️ Стек технологий

- **Фреймворк:** React 18 / Vite / TypeScript
- **Стили:** Tailwind CSS (детская палитра, тактильные 3D-кнопки)
- **Иконки:** Lucide Icons
- **Анимации и эффекты:** Canvas-Confetti, Web Audio API звуковые эффекты
- **PWA:** `vite-plugin-pwa` (манифест, Service Worker, кэширование)
- **База данных и аутентификация:** Supabase (`@supabase/supabase-js` + PostgreSQL)

## 🏃 Запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: `http://localhost:5173`

## 📖 Парсинг CSV со словами

Слова хранятся в файле `Словарь англ. 1-2 класс.csv`. При необходимости изменить или расширить словарь запустите команду:
```bash
npm run parse-words
```
Скрипт автоматически преобразует CSV в `src/data/words.json` строго по требуемой структуре:
```json
[
  {
    "topic_id": "animals",
    "topic_name": { "ru": "Животные", "lv": "Dzīvnieki", "en": "Animals" },
    "words": [
      { "id": "1", "en": "cat", "lv": "kaķis", "ru": "кошка" }
    ]
  }
]
```

## 🌐 Развертывание на GitHub Pages

Приложение настроено для работы на GitHub Pages (используется относительный базовый путь `./`).

### Способ 1: Автоматический (GitHub Actions)
В репозитории уже настроен workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
1. Опубликуйте репозиторий на GitHub:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/DictionaryGames.git
   git branch -M main
   git push -u origin main
   ```
2. В настройках репозитория на GitHub перейдите в **Settings $\rightarrow$ Pages** и выберите **Source: GitHub Actions**.
3. При каждом коммите в ветку `main` приложение будет автоматически собираться и публиковаться по адресу `https://ВАШ_ЛОГИН.github.io/DictionaryGames/`.

## ☁️ Настройка Supabase (Синхронизация прогресса)

Для синхронизации прогресса между телефоном и компьютером:

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. В панели управления перейдите в **SQL Editor** и выполните скрипт из файла [`supabase/schema.sql`](supabase/schema.sql). Он создаст таблицы `profiles`, `topic_progress` и `word_progress` с настроенной безопасностью RLS.
3. Подключите ключи одним из способов:
   - **Способ А (прямо в интерфейсе):** Нажмите в шапке приложения на кнопку **«Синхр.»**, перейдите на вкладку **«Настройки Supabase»** и введите URL и Anon Key. Они сохранятся в памяти браузера.
   - **Способ Б (через .env файл):** Создайте файл `.env` в корне проекта:
     ```env
     VITE_SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co
     VITE_SUPABASE_ANON_KEY=ВАШ_ANON_KEY
     ```
4. Теперь войдите или зарегистрируйтесь под простым детским логином (например, `danik` или `anna@mail.com`) — звёздочки и прогресс будут моментально сохраняться в облаке и подгружаться на любом устройстве!
