# 🌟 WordyMind — Изучение английского и латышского языков для 1–3 классов

Красочное, адаптивное прогрессивное веб-приложение (**PWA**) для школьников 1–3 классов для изучения **английского** и **латышского** языков с переводом на русский и латышский в игровой форме.

---

## 🚀 Особенности и возможности

- 🎓 **Два полноценных режима обучения:**
  - 🇬🇧 **Изучение английского языка** с переводом на русский и латышский.
  - 🇱🇻 **Изучение латышского языка** с переводом на русский язык.
- 🎮 **6 интерактивных игровых режимов:**
  - 🎴 **Карточки (Flashcards):** обучающие карточки с озвучкой, транскрипцией и отметками прогресса.
  - 🔤 **Собери слово (Word Builder):** интерактивный конструктор слов из кубиков-букв.
  - 🧩 **Найди пару (Match Pairs):** сопоставление карточек слов и переводов.
  - 🚦 **Правда или ложь? (True/False):** динамичная викторина-светофор для быстрой проверки знаний.
  - 🎈 **Поймай перевод (Balloon Pop):** аркадная игра с лопанием воздушных шариков с нужным переводом.
  - 🎧 **На слух (Audio Quiz):** тренировка восприятия иностранной речи на слух.
- 🗣️ **Озвучка слов:**
  - 🇱🇻 **Латышский язык:** нативные аудиозаписи слов носителями языка с чистым произношением долготы гласных (*ā, ē, ī, ū*) и мягких согласных (*ķ, ļ, ņ, ģ*).
  - 🇬🇧 **Английский язык:** встроенный синтезатор речи **Web Speech API** со сниженным для младших классов темпом (0.85x).
- 📚 **40 тем и 365 слов** школьной программы 1, 2 и 3 классов с гибким фильтром по классам.

## 🛠️ Стек технологий

- **Фреймворк:** React 18 / Vite / TypeScript
- **Стили:** Tailwind CSS (детская палитра, тактильные 3D-кнопки)
- **Иконки:** Lucide Icons
- **Анимации и эффекты:** Canvas-Confetti, Web Audio API звуковые эффекты
- **PWA:** `vite-plugin-pwa` (манифест, Service Worker, кэширование)
- **База данных и аутентификация:** Supabase (`@supabase/supabase-js` + PostgreSQL)

## 🏃 Запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: `http://localhost:5173`

## 📖 Парсинг CSV со словами

Слова хранятся в файле `Словарь англ. 1-2 класс.csv`. При необходимости изменить или расширить словарь запустите команду:
```bash
npm run parse-words
```
Скрипт автоматически преобразует CSV в `src/data/words.json` строго по требуемой структуре:
```json
[
  {
    "topic_id": "animals",
    "topic_name": { "ru": "Животные", "lv": "Dzīvnieki", "en": "Animals" },
    "words": [
      { "id": "1", "en": "cat", "lv": "kaķis", "ru": "кошка" }
    ]
  }
]
```

## 🌐 Развертывание на GitHub Pages

Приложение настроено для работы на GitHub Pages (используется относительный базовый путь `./`).

### Способ 1: Автоматический (GitHub Actions)
В репозитории уже настроен workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
1. Опубликуйте репозиторий на GitHub:
   ```bash
   git remote add origin https://github.com/ArDiLearn/DictionaryGames.git
   git branch -M main
   git push -u origin main
   ```
2. В настройках репозитория на GitHub перейдите в **Settings $\rightarrow$ Pages** и выберите **Source: GitHub Actions**.
3. При каждом коммите в ветку `main` приложение будет автоматически собираться и публиковаться по адресу `https://ArDiLearn.github.io/DictionaryGames/`.

## ☁️ Синхронизация прогресса через Supabase

Приложение уже преднастроено для работы с вашим проектом Supabase (URL и ключ прописаны в коде):
- **Вход без почты:** школьнику достаточно ввести только **логин** (например, `ivan`, `danik`, `anna`) и **пароль** (от 6 символов).
- Для создания структуры таблиц в Supabase перейдите в **SQL Editor** панели управления Supabase и выполните скрипт из файла [`supabase/schema.sql`](supabase/schema.sql). Он создаст таблицы `profiles`, `topic_progress` и `word_progress` с настроенной безопасностью RLS.
- После входа на компьютере или телефоне прогресс (звёзды, количество изученных слов) синхронизируется автоматически.
